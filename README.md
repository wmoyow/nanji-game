# MOPIKOのなんじでしょう？

子ども向け時計読みクイズアプリ。キャラクター「MOPIKO」と一緒に、4段階の難易度で「なんじ」を当てて遊べます。

- 難易度: やさしい / ふつう / むずかしい / チャレンジ（全10問）
- 正解数に応じた得点イラストが結果画面に表示
- BGM・効果音つき（画面ごとに自動切り替え）

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

Vite + React で構築。詳しい仕様・実装メモは [HANDOFF.md](./HANDOFF.md) を参照。
